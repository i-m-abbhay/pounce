# Changelog

## 0.1.0 - 2026-11-07

First release.

- Notification card for Claude Code `Stop` and `Notification` hooks, showing the project folder and a plain-text snippet of the reply
- Pet that leaves the card, chases the mouse pointer and bats it (`-NoSwat` to turn this off)
- 5 built-in mascots (cat, ghost, robot, blob, frog), `random`, and custom sprite files
- `-Pick` mascot picker with animated previews; the choice is saved
- Taskbar flash; Go to Claude keeps the terminal's maximized state; the card closes itself when you return to the terminal
